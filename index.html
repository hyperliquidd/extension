Why Hyperliquid?

Hyperliquid was built to simplify everyday productivity tasks inside the browser. Instead of installing multiple browser extensions for notes, clipboard management, QR generation, or password creation, Hyperliquid combines everything into one modern lightweight workspace. The extension focuses on performance, simplicity, privacy, and ease of use while maintaining a clean and responsive experience for all users.

Privacy Policy

Effective Date: May 26, 2026

Overview

Hyperliquid respects user privacy and is designed to operate with minimal permissions and without collecting personal information. The extension provides browser-based productivity tools directly inside the browser and does not sell, share, or transmit sensitive user data.

Information Collection

Hyperliquid does not collect, store, or transmit:

  • Personally identifiable information
  • Passwords or account credentials
  • Browsing history or browsing activity
  • Website content or keystrokes
  • Advertising identifiers or analytics data
  • Clipboard content outside user interaction

Permissions & Usage

The extension may request limited browser permissions only for functionality required by specific tools.

  • storage — Used to save notes and preferences locally inside the browser.
  • clipboardRead / clipboardWrite — Required for clipboard copy and paste functionality.
  • https://firestore.googleapis.com/* — Used to fetch a small read-only Firebase configuration value for extension behavior control.

Remote Configuration

Hyperliquid may use a secure Firebase-hosted configuration file to control extension behavior such as displaying tools or loading approved pages. The configuration is read-only and does not execute remote scripts or collect user information.

Third-Party Services

The extension may occasionally use trusted external services required for features such as QR code generation. These services are used only to provide requested functionality.

Data Security

All productivity tools are designed to operate locally within the browser environment. Hyperliquid does not maintain servers for storing user-generated content or personal information.
